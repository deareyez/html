SELLECT / Product Studio homepage

Open index.html in a browser after extracting this ZIP.
Keep all five website files in the same folder. No build step is required.

Files
- index.html: page content
- styles.css: layout and design
- app.js: menu, dialogs, and local inquiry brief composer
- hero-art.svg: main illustration
- favicon.svg: browser icon

Before publishing
- Product Studio is a provisional name. Replace it with your company name.
- Add the real public inquiry email or contact URL.
- The inquiry form creates a copyable brief locally; it does not send messages.
- SELLECT is described as in development. The sample profile is illustrative.

This ZIP contains only the static website and these instructions.
